# finance-control-back
O problema central que o FinanceControl se propõe a resolver é a falta de uma ferramenta web rápida, minimalista e focada exclusivamente no fluxo de caixa mensal (controle de receitas, despesas fixas e variáveis), permitindo que o usuário tenha clareza imediata sobre sua saúde financeira sem atritos de usabilidade.
